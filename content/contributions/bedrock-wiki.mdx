Since 2023, I've made countless contributions to the [Bedrock Wiki](https://wiki.bedrock.dev), a community-written technical documentation
site for learning how to modify the popular sandbox game [Minecraft](https://www.minecraft.net).

These contributions have not only involved writing new documentation for the site, but also extensive rewrites to the core documentation
platform itself (which uses a custom [VitePress](https://vitepress.dev) theme written in [Vue](https://vuejs.org)). This provided me the
opportunity to make substantial changes to a mature platform with the challenge of not breaking the existing documentation.
