DDUIX is a user interface markup language which compiles to JSON files that are compatible with Minecraft's data-driven UI ([DDUI][ddui])
system.

The language syntax (inspired by XML) is supported by the [Visual Studio Code](https://code.visualstudio.com) IDE via a custom language
server extension which provides syntax highlighting, inline errors and autocomplete.

This project exposes multiple packages which can be used to implement DDUIX into existing CI workflows and tooling such as
[Regolith](https://regolith-docs.readthedocs.io).

[ddui]: https://learn.microsoft.com/minecraft/creator/documents/scripting/intro-to-ddui
