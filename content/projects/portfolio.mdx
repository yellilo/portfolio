A simple portfolio website built using [React Router](https://reactrouter.com)'s static site generation and deployed on
[Netlify](https://www.netlify.com) via continuous integration. Content sections (like this one) are generated from individual
[Markdown](https://www.markdownguide.org) files using [MDX](https://mdxjs.com).

The glowing effect on this site (desktop only) was inspired by the Windows 10 start menu and is primarily CSS-driven, making use of modern
features such as [relative colors][relative-colors] and [`background-clip: text`][text-background-clip].

[relative-colors]: https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Colors/Using_relative_colors
[text-background-clip]: https://developer.mozilla.org/docs/Web/CSS/Reference/Properties/background-clip#text
